# 自定义农场 · custom-farm

给 Coopanion 桌宠的种田扩展：18 种作物只是起点。**农作物、杂草、装饰物、天气、状态、道具、合成表和贴图都能在面板里完全自定义**——想种什么、长什么样、吃什么补什么，全由你决定。

桌宠在**任务栏上沿**种地：任意多棵（不能重叠）、浇水会干、太久不浇会枯萎、
有的作物能反复收；收下来的东西**掉在地上**，桌宠要走过去捡，捡起来才进背包。

## 1. 玩法

| 要素 | 说明 |
|---|---|
| 种多少 | 任意多棵，上限 `maxPlants`（默认 12）。默认**允许轻微重叠**（`cropGapScale`=0.8）；设 1 就按贴图宽度**刚好不重叠**（统一 2 倍缩放，像素宽 = 屏幕上真实占位） |
| 位置 | 每棵有 `x`（0 最左、1 最右，占工作区宽度）；播种时由桌宠指定或世界随机挑。草地**永远铺满整条底边**（贴图循环），`farmCells`（12~48）缩放草地/作物/野草贴图和草地厚度；所有作物/野草位置按中心比例缩放。缩放后落到可种范围（屏幕/农田）外的作物删除并退 1 包种子；缩小时新野地补杂草，也能种。桌宠按缩放后的 x 找作物 |
| 生长 | 每棵按等级攒生长点，等级数/总点数/能收几次都取自游戏表（见 `src/crops.js`）。1 个游戏日 = `realMinutesPerDay` 真实分钟；**桌宠关掉/电脑睡眠期间不补天**，回到游戏最多补 `maxStepDays`（默认 1）个游戏日，不会一觉醒来跳几十天 |
| 水分 | 土越湿长得越快；干透后 `wiltMinutes` 内不浇就**枯萎**（不单独推事件），枯了浇不活，重种会把它拔掉 |
| 收割 | **产物掉在地上**（`drops`），每次产量按游戏表的 `min_count~max_count` 随机；落地时会往左右弹一小段；要用 `farm_collect` 捡进背包。番茄收 4 次、草莓 5 次，收完退回 `repeatLevel` 继续长；**土豆/玉米/南瓜/胡萝卜只能收 1 次，收完就拔掉**。桌宠查田时能看见「最近田里的变化」（谁因为什么没的） |
| 背包 | `inventory` 记每种产物数量；HUD 显示件数 |
| 事件 | `farm.ripe`（哪几棵熟了 + 位置）、`farm.dry`（缺水）、`farm.state`（吃东西）；`farm.day` 默认关，`dailyEvent=true` 才推 |

## 2. 工具

| 工具 | 用途 |
|---|---|
| `farm_status` | 每棵的位置/等级/进度/水分/是否可收或枯萎 + 背包 + 地上的掉落物 + **最近田里的变化（少了哪棵、为什么）** |
| `farm_stand` | 站到某个位置，`at` **必填**（`pet_move_to` 回执里的百分比 / 100） |
| `farm_plant` | 在脚下种一棵（`crop` 可选，`x` 可选）；**消耗 1 包对应种子**，没有种子会让你先买 |
| `farm_water` | 浇水（**要走到跟前**，先 pet_move_to + farm_stand），不填 `plot` 就浇脚下这片 |
| `farm_harvest` | 收脚下这棵熟的，**产物掉地上**；回执会提示背包里可卖多少 |
| `farm_collect` | 把脚下的掉落物捡进背包 |
| `farm_consume` | 吃掉背包里的作物/杂草收获物或消耗品，缓解「饥饿」这类状态（要主人在状态自定义里配好消耗行为） |
| `farm_craft` | 按「道具合成表」消耗背包材料合成道具；不填 `recipe` 就列出所有表 |
| `farm_shop` | 看商店：列出所有设了购买价的种子/消耗品/装饰（买价、卖价） |
| `farm_buy` | 买设了购买价的道具（种子/消耗品/装饰）；买来先进背包 |
| `farm_sell` | 卖背包里有出售价的道具；没设出售价的不能卖 |
| `farm_place` | 把装饰道具放到地上（`item`、`x`）；上层装饰会清掉落点杂草，下层不会 |
| `farm_bag` | 打开背包面板（独立 WPF 窗口） |

### 走过去的协议

```
farm_status                 → 3 号玉米熟了，在 62%；地上有个番茄在 40%
pet_move_to {x: 0.62}      → 沿屏幕底边走过去
farm_stand {at: 0.62, plot: 3}
farm_harvest  {plot: 3}    → 产物掉在 62%
farm_collect               → 捡进背包（图层会播"吸到身上"）
```

## 4. 调参（`worlds.farm`）

| 键 | 默认 | 说明 |
|---|---|---|
| `pointsPerDay` | 288 | 每个游戏日的生长点（**由游戏数据反推，别乱改**） |
| `realMinutesPerDay` | 8 | 1 游戏日 = 多少真实分钟（**这个是我定的**，想快就调小） |
| `maxStepDays` | 1 | 一次刷新最多推进几个游戏日。关机/睡眠回来只补这一天，防止"存档跳天 + 田全枯"；设大 = 允许离线生长 |
| `maxPlants` | 12 | 同时最多几棵 |
| `zoom` / `screenWidth` / `spriteGapPx` | 2 / 2048 / 4 | 用来把贴图像素宽换算成最小 x 间距（要和图层一致） |
| `cropGapScale` / `cropGapPct` | 0.8 / 0 | 间距倍率（1 = 刚好不重叠）；`cropGapPct >0` 时直接按屏宽百分比强制最小中心距 |
| `farmCells` | 48 | 农田整体大小（12~48 格，48=满宽）。底边草地始终铺满/循环；缩放草地/作物/野草贴图和厚度，所有位置按中心比例缩放。缩放后落到可种范围外的作物删除并退 1 包种子；缩小时新野地补杂草且可种 |
| `dryPerDay` / `wiltDays` | 0.15 / 2.2 | 每个游戏日蒸发多少水分 / 干透多久枯萎（游戏日） |
| `waterGain` | 1.0 | 浇一次补多少水分（1 = 浇满） |
| `startCoins` | 120 | 新开局金币（老存档不动） |
| `tickIntervalMs` | 5000 | 刷新间隔（固定节拍，不是随机刻；只影响状态/事件及时性，不改变生长速度） |

## 5. 验证

```powershell
node tools/selftest.mjs     # 166 项
node tools/gen-describe.mjs # 改了工具/事件后
```

覆盖：不重叠判定、任意数量、生长与成熟事件、收割只掉不进包、走远了捡不到、
多次收获（番茄收 4 次后拔掉）、枯萎与拔掉重种、浇水、种子（没种子不能种/买种子进背包/种下扣 1 包/
种子能卖/钱不够提示可卖/一次买多种只扣总价/种子用完时新的一天推补货询问）、背包、存档迁移（v2→v3、老存档补种子）、
写盘失败要报错、**离线/睡眠回来只补 `maxStepDays` 天（不跳天、不抽干土）**、**田地大事记（收满/拔枯/缩放删掉都记账）**。

### 已知事故：关机一晚，存档跳了几十天、田全枯

原因：`advance()` 用"上次 tick 的时间戳"算游戏时间，桌宠关掉/电脑睡眠后第一次 tick 会把整段真实时间**一次补完**。
`realMinutesPerDay=8` 时关 5.4 小时 = 40 个游戏日；`60` 时关 12 小时 = 12 天。天一跳，水也一次扣光，作物随后全部枯死。

修法：`advance()` 单次最多推进 `maxStepDays`（默认 1）个游戏日，剩下的不补；桌宠查田时用「最近田里的变化」
说明每棵是怎么没的。`selftest` 新增 3 条时间断言 + 5 条大事记断言。

## 6. 坑

1. 改完代码必须 `POST /api/run/restart`（`/api/worlds/restart` 不重新 import）。
2. World 的 `stop()` 会存档：重开局要 disable → 删 → enable，或直接用 `reset-farm.ps1`。
3. **PowerShell 变量名大小写不敏感**这条坑在这个项目里出现过两次（`$leaf`/`$LEAF`、`$shots`/`$Shots`）。
4. 生成代码别用普通模板字符串写 `'\n'`（会被提前解释成真换行）。

## 7.6 「农场自定义」页


同一页的**农场自定义**页签（`panels: [{ id: 'customize' }]` + `dist/webui.js`），最上面是「设置模板」，下面五块用横线隔开：

- **设置模板 ZIP**：把当前 `custom.json` 和 `assets\sprites\cust_*.png` 打包下载；导入会覆盖全部设置和贴图，但**不会清空存档**（田地/背包/金币不变）。导入前建议先导出备份；如果新模板删掉了存档里正在种的作物，田里会按新设置重新解释。
- 模板里也带一份 `template.json`（格式/版本/导出时间），导入时会校验；文件名形如 `custom-farm-template-20261028-0230.zip`。
- 模板包含 `custom.json` 里的农场/作物/杂草/状态/道具/合成表，以及**面板里的设置覆盖**（农田大小、作物上限/密度/大小、时间/浇水）。不含存档；游戏配置页剩下的野草/金币/图层开关仍按本机配置走。


| 区块 | 能做什么 |
|---|---|
| **农场** | 从 3 张 Grok 内置长条地板里选（默认 0 号，96px 长条按原宽自动重复铺满，最后一列裁切）；**地表高度（像素，2~40，默认 4，约到桌宠鞋底）**；添加/删除自己的 PNG；**农田整体大小（格）** |
| **农作物** | 增删作物；阶段数 2~8；每阶段（N-1 段）成长天数；各阶段 / 种子 / 收获物贴图；内置作物可「恢复默认」。**最多同时种几棵、作物间距倍率/最小间距、农作物/杂草大小倍率、掉落物大小倍率**；价格/能不能吃/吃掉效果在「道具自定义」页 |
| **杂草** | 增删杂草；阶段数 2~8；每阶段天数；出现权重（按权重占比决定出现概率）；**图层（上=和作物/桌宠同前台层；下=背景层、作物后方）**；可选收获物名字 / 价值 / 贴图；内置三种（野草、变种、伊甸花）可恢复默认。**野草上限、开局补草数量、每游戏日出现概率、播种铲草半径** |
| **生态** | 一个游戏日 = 多少真实分钟、单次最多推进几个游戏日、刷新间隔、是否每天推「新的一天」；**浇水三项**（每游戏日蒸发 / 一次浇水补水 / 干透后枯萎天数） |
| **浇水特效 / 枯萎** | **浇水特效动画**：植株上方落水帧序列 + 地面水花帧序列，各自可增删帧、改帧间隔；**枯萎作物贴图**：换图 / 用默认。浇水数值在「生态」 |

- 数据存在 `%LOCALAPPDATA%\Programs\Coopanion\data\home\companion\data\farm\custom.json`；
  上传的 PNG 复制到 `Pet\assets\sprites\cust_*.png`（overlay 只认 `.png`，单张 ≤ 4MB、≤ 2048×2048）。
- 自定义作物默认**只收一次**（没有多次收获字段）；种子的买价/卖价在「道具自定义」的种子栏设置。
- 田里还种着/长着的时候不让删（会报错）；至少留一种作物。
- 面板的贴图预览走 `invokeBinary('sprite')`，选贴图走 `ctx.pickPath`（本机原生文件框）。
- 浇水特效写在 `state.waterFx`（`pour` / `burst` 帧名数组 + `pourMs` / `burstMs`），枯萎贴图写在 `state.wither`；overlay 读到空数组就不播那一组，读不到或文件不在就退回内置素材。
- 页签的标题来自 `webUi().panels[].title`；`package.json` 的 `cortico.webUiClient` / `webUiStyle` 指向 `dist/`。

## 7.7 「状态自定义」页

同一页的另一个页签（`panels: [{ id: 'status', title: '状态自定义' }]`），用来定义自己的数值/开关状态：


| 元素 | 说明 |
|---|---|
| **数值状态** | 名字、最小值/最大值、初始值、每游戏日变化（可负，比如饱食度 -5/天）、单位；卡片里可以直接「设为」当前值 |
| **开关状态** | 只有「初始生效」；作为条件的目标（比如「饥饿」） |
| **条件** | 当 `[数值状态] [< <= > >= == !=] [阈值]` 成立时，让 `[目标开关]` 生效；多条规则指向同一个开关时按「或」处理 |
| **消耗行为** | 触发状态生效（开关生效 / 数值 > 0）且冷却到了，就从选中的道具里吃掉 `count` 个，并把 `变化量` 加到指定数值状态（例如 `饥饿 → 吃番茄×1 → 饱食度 +25`）；关掉「自动消耗」就只推事件提醒桌宠 |
| **添加示例** | 一键补齐「饱食度」0~100、初始 100、每天 -5，「饥饿」，条件 `饱食度 < 30 → 饥饿`，消耗行为 `饥饿 → 吃作物/米饭/意面 ×1 → 饱食度 +25`（0.5 天冷却，自动），并给所有食物补默认效果。默认配置已经带这些；删掉后想恢复就点它（幂等，不会重复加） |

- 定义存在 `custom.json` 的 `states` / `rules` / `consume`；当前值存在存档 `state.states`，冷却进度存在 `state.stateActions`，重启/离线都保留。
- 每次 tick 按游戏日漂移、重算条件，然后跑消耗行为；自动消耗成功会推 `farm.state` 事件（「饥饿生效：吃掉了番茄×1，饱食度 +25」）。
- 手动「设为」会立刻按条件重算并落盘（不用等下一拍）；改状态名/删除状态时，引用它的条件和消耗行为会自动清理。
- 数值状态只负责漂移和作为条件来源；开关状态由条件规则决定（没有规则指向它时保留手动值）。
- 桌面宠物也可以不等冷却、主动用 `farm_consume {item:'tomato'}` 吃一个；同一套消耗行为决定吃哪些道具、加多少状态。

## 7.8 「道具自定义」页

## 7.11 「环境提示词」页

设置页最右边原来的「自定义农场」页签改名为 **「环境提示词」**（`promptDocs` 的 `title`）。它不是作物/价格表单，而是发给桌宠的 `src/ENV_PROMPT.md`：

- **静态文字**：改前面的作物、价格、阶段、道具设置**不会自动改这一页**；具体数字以 `farm_status` / `farm_shop` 的实时回执为准。为了避免误导，原来的写死作物表/价格表已经删掉。
- **吃饭与状态**：新增一节，明确告诉桌宠：看到「饥饿」或饱食度偏低时先提醒主人，主人同意后用 `farm_consume` 吃一个；不要自己改状态数值。想让它主动维持饱食度，直接在这一节加/改句子。
- **状态对桌宠的影响**：也写在这一页（语气、提醒时机、先问主人还是直接吃）。状态的范围、阈值、触发条件仍在「状态自定义」；这里只负责“看到状态后怎么做”。
- 顶部用 HTML 注释给主人说明这一页的用途/不会自动同步/如何写吃饭提示；注释在渲染后通常不显示。
- 保存后下一次对话 / 唤醒生效；页面内容仍然是 Markdown，可以直接改。


## 7.12 背包页 / 游戏配置 / 图标继承


- 设置页**最左边**是「背包」页（`panels: [{ id: 'bag' }]`），「商店」页紧挨在它右边；背包页四栏用横线隔开：
  - **背包**：4 列图标格，数量 + 卖价；`卖 1` / `全卖`；装饰道具还有 `放置` 按钮。
  - **放置**：点「放置」后出现坐标输入（0~100%），预览里用虚线和半透明贴图标出落点；确定后才真正扣背包并放下。
  - **农场预览**：按当前田地的 x 坐标画出作物和装饰；下层装饰在作物后，上层装饰在作物前。
  - **农场里的道具**：和背包一样的图标格，**每一株作物 / 每一个装饰单独一张卡，不按类型合并**；卡片显示所在横坐标（如 `农作物 · 12%`）。点某张卡的图标，预览只高亮这一株/这个装饰；农作物「铲除」、装饰「回收」都只作用于这一个实例。
  - **手动合成**：选配方、填数量，显示每种材料的「拥有 / 需要」和产物；材料够就点「合成」，直接扣材料、加产物（和 `farm_craft` 用同一批合成表）。
  - 数据从 `#bagInvoke` 的 `state` 读取；买卖/合成/放置/铲除/回收都走同一套后端，和 WPF 背包一致。
- **商店**独立页：只列 `buy > 0` 的道具，显示 `￥买价`；`买 1` 进背包。
- 设置页原来的「配置」页签显示为 **「游戏配置」**（宿主的配置页文案是固定的，客户端 bundle 在农场页把它改成这个标题；现在只剩新开局金币 / 图层开关）。
- **右键菜单的「背包」入口及其图标已移除**：不再修改 `cortico-world-desktop-pet` 的安装文件，也没有配置开关。需要 WPF 背包时用 `farm_bag` 工具或手动运行 `bag\bag.ps1`；设置页的 WebUI 背包仍然可用。WPF 背包里装饰道具仍可放到 50%；WPF 商店和背包使用同一套 64px 图标格 / 48px 图标。
- **装饰图层**：道具页每个装饰可选「上」或「下」；上层画在 weeds 层（和杂草同层，在桌宠/作物上方，落点清草），下层画在 background 层、作物之前（在农作物后方，不清草）。可同时叠放，不互相阻挡。
- 「道具自定义」里的种子/农作物卡片**图标自动继承**作物设置里的种子/产物贴图（改农场自定义的贴图后，道具页图标跟着变；不需要再单独上传）。装饰道具的「放置」已从道具页移到背包页。

## 可迁移 / 打包

扩展里没有任何写死的绝对路径：`src/paths.js` 从扩展自身位置推出 `<Pet>\overlay\`、`<Pet>\bag\`、`<Pet>\assets\`。
整个 `Pet` 文件夹拷到另一台机器，跑 `scripts\install.ps1` 就能用（详见 `..\docs\PACKAGE.md`）。
扩展被复制（而不是 link）时，用环境变量 `PET_HOME` 或 World 配置项 `petRoot` 指定 `<Pet>` 在哪。
