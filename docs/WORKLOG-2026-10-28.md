## 2. 已完成功能

- 18 种 FarmCrops 免费素材作物：阶段、种子、产物图标。
- 种植、浇水、生长、收获、掉落、拾取、商店、金币、背包。
- 合成表并入「道具自定义」，不再单独占顶层页。
- 删除道具时同步清理引用它的合成表。
- 稻穗 `rice_ear` 缺失自动恢复，并补 `rice_ear → rice`。
- 生态自定义：生长条件 + 天气。
- 天气：无风 / 微风 / 大风 / 彩蛋；可增删、无风不可删。
- 每种天气可配持续时间、权重、作物/装饰各自方向与角度、压扁幅度、速度。
- 天气「预览 5 秒」「立即生效」。
- 彩蛋：只压扁/拉伸，无旋转；所有贴图同相位。
- 无风默认角度：`4°`。
- 心情：`mood` 0~100，初始 60；`happy >= 70`，`bored < 30`。
- 天气按真实分钟结算心情：无风 +2、微风 +1、大风 -6、彩蛋 +4；默认 10 分钟。
- 吃东西 +8 心情。
- 状态行为只在进入 `happy` / `bored` / 饥饿时触发一次；持续期间不重复。
- 小木屋 `deco_cabin`：买 350 / 卖 120，bottom 层。
- 游戏配置「隐藏农场」。
- 扩展图标：花盆图，`cortico.icon = assets/icon.png`。
- 默认设置改成当前用户配置。

## 6. 已知问题 / 风险

- **npm token 暴露**：两个 token 曾出现在聊天；必须到 npm Tokens 页面撤销。本归档不保存 token 值。
- **标准安装器未验收**：`Setup /S` 返回 0，但未完整部署/注册卸载项；当前 0.2.13 是手工从安装包 `app-64.7z` 展开的。要标准安装，请用图形界面 Setup，选择继承现有 data。
- **卸载 App 后扩展自动回来**：因为 `data/extensions` 被保留；不是自动重装。想干净重装需只保留 `data/home`，删除 `data/extensions`。
- **本地 link 素材消失**：`Copy-Item` 把 junction 展开成普通目录，导致找不到父级 `Pet/assets`；已重新建 junction。
- **`custom-farm/assets` 为空**：`postpack` 会清理临时 staging；npm tarball 内有 330 PNG，这是正常的。
- **备份完整性**：备份约 1.6 GB，存在 junction/长路径读取错误；`home/config/custom.json` 已核对，完整恢复前仍需校验。
- **Electron 限制**：缺少精确双层 z-order、桌宠显示/隐藏联动、多屏跟随。
- **当前 App 扩展版本**：显示 `0.33.3`（本地 link），npm 最新为 `0.33.6`；需要升级/重载。
- **跨平台**：macOS/Linux 未实机测试；`os` 字段已写 all，`experimental` 标签仍在。

## 16. v0.38.0（2026-10-29 上午）

- 移除 `electron` npm 依赖；安装扩展不再下载第二份 Electron，解决“能下载但写不进 `node_modules/electron` / 安装后图层起不来”。
- 默认图层引擎改「自动」：检测到备用 Electron 就用，否则 Windows 用 WPF；不会因为缺 Electron 安装失败。
- 游戏配置顶部新增「环境自检」：检查 `electron.exe` 和 WPF 脚本，明确提示“缺少 Electron 运行时”或“WPF 可用”；提供图层引擎切选单和备用 Electron 路径。
- 第一次启用时自动做一次环境自检；如果当前引擎缺运行时，推一次 `farm.env` 事件让桌宠把问题和修复方式转告主人，之后不再重复提醒。
- `launch.js` 支持 `--electron <path>`；World 只把检测到的可执行文件传进去，不再隐式 `require('electron')`。
- WPF 回退改为 WebView2 宿主：`overlay/overlay-webview.ps1` 加载与 Electron 相同的 `renderer.html/renderer.js` 和素材，缩放、阴影、粒子、水滴等视觉一致；窗口保持透明、置顶、点击穿透。
- 环境自检增加 WebView2 脚本、SDK 库、运行时检查；自检失败仍推 `farm.env`。
- 图层拆成 bg/top 两个窗口，Electron 用两个 BrowserWindow，WPF/WebView2 用两个宿主；`bg` 在桌宠下，`top` 为桌宠 owned window，按 `layer` 分配贴图。
- 新增 `zorder` 守护（约 1s，句柄变化才重排）：桌宠重新置顶、显示/隐藏、点击或窗口重建后重新挂 owner / 重放 bg，避免整个图层翻转。
- 农作物设置新增「图层」上下选择（和杂草一样）；顶层作物在 `top` 窗口绘制，默认 `bottom`。
- `package.json` 的 `os` 收紧为 `["win32"]`；macOS / Linux 暂不发布，等后续实测。
- 版本 `0.38.0`。
