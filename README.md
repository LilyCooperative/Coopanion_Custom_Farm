# 自定义农场（Custom Farm）

给你的桌宠自定义一个农场，让它开心地生活。

**18 种作物只是起点。** 农作物、杂草、装饰物、天气、状态、道具、合成表和贴图都能增删、改数值、换图；想种什么、长什么样、吃什么补什么，全由你决定。

> 独立 WPF 背包已移除；背包、商店、农场预览、摆放和手动合成都在 WebUI。

## 玩法

- **种**：桌宠走到田里，消耗 1 包种子种下一棵；不同作物有不同阶段和生长天数。
- **浇**：土会变干，浇一次浇透脚下一片；太久不浇会枯萎，枯萎后只能拔掉重种。
- **收**：熟了的作物可以收，产物**掉在地上**，再走过去捡进背包。
- **重复收**：番茄、草莓、黄瓜、红辣椒、蓝莓、茄子等可以收多次；土豆、玉米、南瓜等收一次就拔掉。
- **买卖**：作物、种子、消耗品、装饰可以卖；种子、食材、装饰可以在商店买。
- **消耗与状态**：作物和食物可以消耗，默认同时增加**饱食度**和**心情**；饱食度低于 30 会进入「饥饿」，默认从所有可消耗道具里随机消耗，不通知桌宠；也可以改成「桌宠主动消耗」让它自己挑。
- **做菜**：用合成表把食材做成蛋炒饭、番茄炒蛋、意大利面等。
- **动物**：鸡等动物默认在中层（可在动物自定义切上/中/下）随机游走/啄食，成年后定时掉蛋；幼崽可买、可卖，成年可卖，产物要走过去捡。
- **杂草**：田里会长杂草，可以拔掉，也可以收成道具。
- **桌面图层**：草地、作物、杂草、装饰、掉落物、浇水特效、天气摇摆都在任务栏上沿渲染；背包和商店在 WebUI 里。

## 可以自定义什么

- **农作物**：增删作物、阶段数、每阶段天数、产物卖价、种子买价、各阶段/种子/产物贴图。
- **杂草**：增删杂草、阶段与天数、出现权重、上/中/下图层、收获物名字/价值/贴图。
- **地面**：内置草皮、导入自己的 PNG、地表高度、农田缩放倍率。
- **装饰物**：图标、摆放贴图、上/中/下图层、缩放、买价卖价。
- **天气**：增删天气（无风不可删）、持续时间、权重、作物/装饰摇摆方向与幅度、压扁幅度、速度、心情变化。
- **状态**：数值状态、开关状态、条件规则、消耗行为（随机消耗 / 桌宠主动消耗；消耗品池默认所有可消耗道具）。
- **道具**：种子/农作物/消耗品/装饰的买价卖价、能不能吃、吃掉后的状态效果、图标。
- **合成表**：1~4 个材料合成 1 个产物，桌宠可以用 `farm_craft` 合成。
- **设置模板 ZIP**：在「游戏配置」顶部导出/导入全部设置、参数和引用贴图；可用「田园农场」默认模板（不含存档）。
- **环境提示词**：发给桌宠的静态提示词，写“收到状态事件怎么消耗、什么时候提醒主人”等。
- **安装路径**：在「游戏配置 → 安装」里直接改，改完自动搬运并重启图层。

## 安装

### 从 Coopanion 扩展页安装（推荐）

在 Coopanion 扩展页搜索「自定义农场」或 `@lily-cooperative/custom-farm`，安装后启用 World。

扩展包自带 `overlay` / `overlay-electron` / `assets`，第一次启动会复制到安装目录，不需要另外准备项目文件夹。

### 本地开发

```powershell
# 注册本地 link
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1

# 改完扩展代码后重启进程
Invoke-RestMethod -Method Post http://127.0.0.1:17788/api/run/restart

# 只重建 World（不会重新 import 源码）
Invoke-RestMethod -Method Post http://127.0.0.1:17788/api/worlds/restart
```

## 游戏配置

- **环境自检**：页面顶部检查 Electron/WPF（WebView2）运行时；显示「缺少 Electron 运行时」或「WPF/WebView2 可用」；第一次启用如果缺运行时，会推一次事件让桌宠转告主人
- **性能**：图层节流可选「不节流（默认）/ 自动 / 节流」；改完自动重启图层，默认不节流以保证收获动画跟手
- **图层引擎**：自动（有备用 Electron 就用，否则 WPF/WebView2）/ 备用 Electron / WPF（WebView2）；不会为了安装扩展下载 Electron；WPF 回退也加载同一套 `renderer.html/renderer.js`，视觉与 Electron 一致
- **安装路径**：默认 `<Coopanion 数据目录>\custom-farm`；修改后自动停图层、搬目录、重启
- **显示器**：「自动」用主屏，或从下拉里选择任意一块屏幕；Electron 图层会在约 1 秒内移动过去，WPF/WebView2 回退也使用主屏
- **备份存档**：把 `state.json` 和 `custom.json` 复制到 `data\farm\backups\backup-时间\`；「读取存档」只恢复 state.json，若里面有当前设置中不存在的物品/动物会警告并拒绝读取
- **重置一切**：先自动备份，再清空存档和全部自定义设置，World 自动重启；安装路径和上传的 PNG 不会被删
- **模板**：「设置模板」在「游戏配置」顶部；导入前会提示模板变更可能影响背包已有物品
- **图层窗口**：拆成 `bg` / `mid` / `top` 三个透明窗口；`bg` 在桌宠下面，`mid` 在桌宠后方、下层前方，`top` 是桌宠的 owned window；野草/装饰/作物/动物按 `layer` 设置分配
- **层级守护**：每 500ms 重新确认桌宠窗口；桌宠重新置顶、显示/隐藏、被点击或窗口重建后，自动重新挂 owner / 把 `bg` 放回桌宠下面，防止图层整体翻转

存档和自定义配置固定在 `data\home\companion\data\farm\`，不会跟着安装路径搬走。

## 默认内容

- 18 种作物：土豆、胡萝卜、番茄、草莓、玉米、南瓜、甜菜根、蓝莓、小白菜、花椰菜、黄瓜、茄子、大蒜、菠萝、小萝卜、红辣椒、红洋葱、西瓜。
- 默认饱食度 0~100（初始 100，每游戏日 -5，低于 30 进入饥饿）；心情 0~100（初始 60，>=70 开心，<30 无聊）。
- 每种作物、米饭和意大利面默认同时加饱食度和心情；蛋炒饭、番茄炒蛋、鸡蛋、鲜肉也带效果。
- 默认天气：无风、微风、大风、彩蛋；默认商店和 4 张食物合成表。

完整的食物数值、作物表、默认参数见 [custom-farm/README.md](custom-farm/README.md)。

## 文件与数据

| 路径 | 作用 |
|---|---|
| `custom-farm/` | 扩展本体：`src/` 逻辑、`dist/` WebUI、`tools/` 自测和打包脚本、`icon.png`、`describe.json` |
| `overlay/` | WPF 回退（WebView2 加载同一套渲染器） |
| `overlay-electron/` | Electron 桌面图层 |
| `assets/sprites/` | 内置作物/杂草/地面/装饰/图标 PNG |
| `scripts/` | 本地安装/停用脚本 |
| `docs/` | 打包和发布说明 |

数据文件：

- 存档：`data\home\companion\data\farm\state.json`
- 自定义配置：`data\home\companion\data\farm\custom.json`
- 上传贴图：`<安装目录>\assets\sprites\cust_*.png`
- 配置：`data\home\companion\config.json` → `worlds.farm`

## 兼容性

- Coopanion `>= 0.2.13`，World API `6`
- Node.js `>= 22`（Coopanion 自带）
- Electron 不是 npm 依赖；有备用 Electron 就用，Windows 没有时用 WPF/WebView2（同一套渲染器）
- WPF 回退需要 Windows 10/11 的 WebView2 Runtime（系统一般自带）
- 仅 Windows 10/11；macOS / Linux 暂不支持，等后续测试
